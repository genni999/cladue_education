# 팀별 실적 취합 도구

양식이 서로 다른 여러 팀의 실적 파일을 매달 자동으로 취합·정리하는 도구. `취합.py` 하나로 동작하며, `openpyxl`만 사용한다 (pandas 아님).

## 명령어

```
python 취합.py                # 이 폴더 아래 '...yyyy-mm' 폴더 중 가장 최근 것만 취합 -> {yymm}_취합.xlsx
python 취합.py 1차_2026-01     # 폴더를 직접 지정해 그 달만 취합
python 취합.py --누적          # 산하 모든 '...yyyy-mm' 폴더를 처음부터 다시 읽어 누적 파일을 새로 생성
```

- 월별 산출물: `{yymm}_취합.xlsx` (실행마다 그 달 파일만 새로 씀, 다른 달 파일엔 영향 없음)
- 누적 산출물: `실적_누적_{yymmdd}_{n}.xlsx` (yymmdd=실행 날짜, n=같은 날짜 안에서의 실행 순번. 기존 파일을 덮어쓰지 않는다)
- `실적_누적양식.xlsx`는 **정답/참고 자료**이며 스크립트가 건드리지 않는다 (실제 산출물과 셀 단위로 대조해 검증 완료).
- `sample.xlsx`는 출처 불명 — 스크립트가 만든 파일이 아님. 필요 없으면 정리 대상.

## 입력 데이터 구조

각 `...yyyy-mm` 폴더(예: `1차_2026-01`)에 팀별 실적 파일과 환율표 1개가 들어있다. 양식은 4종류이고, 팀마다 다르다 — **팀 이름과 양식을 코드에 고정하지 않고 표식으로 찾는다**:

| 양식 | 판별 표식 | 비고 |
|---|---|---|
| 표준 세로형 | 「계정」/「Account」 셀, 같은 행 오른쪽에 품목명들 | 행=계정, 열=품목 |
| 오프셋형 | 「계정」 셀은 있지만 품목명은 한 행 아래 | 표가 오른쪽·아래로 밀려 있음, 위쪽 몇 행은 제목/작성자 등 메타 정보 |
| 가로형 | 「품목」 셀, 같은 행 오른쪽에 계정명들 | 행=품목, 열=계정 (다른 양식과 행/열이 반대) |
| 품목별 시트형 | 「Account」 셀, 값 컬럼 헤더가 "Amount" 같은 일반 단어 | 시트 하나 = 품목 하나 (품목명은 시트명에서 가져옴), 계정명이 영문 |

환율표는 「통화」「구분」「원화환율」 헤더로 찾는다. **월평균** 환율만 쓴다. KRW는 환산하지 않고 적용환율 1.0.

계정명 동의어(판관비=판매관리비=판매비와관리비, 매출=매출액, Revenue=매출액 등)는 `ALIASES` 딕셔너리로 표준화한다. 소계 계정(매출총이익·영업이익·세전이익)과 "Total" 합계행은 인식은 하되 결과에는 담지 않는다. 매핑에 없는 계정명은 조용히 버리지 않고 경고로 출력한다.

## 기준월 판별

기본은 폴더명(`...yyyy-mm`)에서 가져온다. 단, **시트 이름 자체가 월코드(YYMM, 예: `2601`)인 경우 그 시트의 기준월로 우선 사용**한다 (자원1팀 파일이 이 방식). 한 파일에 여러 시트가 있고 그중 일부가 자신이 속한 폴더와 다른 월을 가리키면(예: 2월 폴더의 파일 안에 `2601` 시트가 같이 온 경우), 그 데이터는 원래 그 팀이 제출했던 값과 다를 수 있어(정정본) `정정여부` 컬럼에 `정정`으로 표시하고, 같은 조합의 기존 `원본` 행은 지우지 않고 둘 다 남긴다.

환율은 팀 파일이 속한 폴더의 환율표가 아니라 **그 레코드의 기준월에 해당하는 환율표**를 찾아 적용한다 (`load_all_fx_rates()`가 모든 폴더의 환율표를 기준월별로 미리 모아둠) — 지난달 시트가 최신 폴더에 섞여 와도 그 달 고유 환율을 쓰기 위함.

월별 모드(`python 취합.py <폴더>`)는 그 폴더 자신의 기준월과 다른 데이터를 산출물에서 제외한다(경고로 안내). `--누적` 모드는 전부 포함한다.

## 출력 스키마

`기준월, 팀, 품목, 계정, 통화, 현지금액, 적용환율, 원화금액, 정정여부` (8+1 컬럼, `실적_누적양식.xlsx`와 동일한 앞 8컬럼 + 정정 여부 컬럼 추가).

## 규칙 (확정)

- 환율: 월평균 사용. KRW는 환산하지 않음(적용환율 1.0).
- 계정: 소계(매출총이익·영업이익·세전이익)와 Total 행은 결과에 담지 않음. 실수치 4개(매출액·매출원가·판관비·영업외손익)만 담음.
- 매핑에 없는 계정명은 경고 후 건너뜀 (조용히 버리지 않음).
- 같은 기준월·팀·품목·계정 조합이 여러 파일에서 발견되면(정정본 등) 둘 다 남기고 `정정여부`로 구분한다. 어느 쪽이 "맞는" 값인지 최종 판단은 아직 안 함 — 후속 검증 단계에서 다룰 문제.

## 알려진 이슈

- `자원1팀_2602.xlsx`에는 `2601`(지난달) 시트가 함께 들어있고, 원본 1월 파일과 일부 수치가 다름(정정본으로 추정). `--누적` 결과에는 원본/정정 두 버전이 모두 남는다 — 최종 채택 값을 정하는 로직은 아직 없음.
