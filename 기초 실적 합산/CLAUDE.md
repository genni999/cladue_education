# 부서별 경비 정리 도구

부서별 경비 엑셀 파일을 읽어 정리하고 합계를 계산하는 도구.

## 규칙

- 원본 파일은 수정하지 않는다. 결과는 `출력/` 폴더에만 쓴다.
- 결과를 낼 때마다 검증 결과를 같이 출력한다.

## 작업 체크리스트

- [x] 엑셀 읽어서 표로 만들기 (`scripts/01_read_table.py`)
- [x] 합계 계산 (`scripts/02_sum.py`, `scripts/정리.py`)
- [x] 검증 코드 붙이기 (부서 소계·총계 대조, [PASS]/[FAIL] 형식)
- [x] 다음 달에도 돌아가게 정리 (`scripts/정리.py`에 월 코드/파일명 인자 추가, 출력 파일명에 월 태그 부여)
