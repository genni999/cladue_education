# MGB 공개 지리정보 다운로더

필리핀 광업지질국(MGB)이 ArcGIS Experience 대시보드로 공개한 광업·지질 데이터를
찾아서 GeoJSON / CSV로 내려받는 웹앱입니다.

대시보드 화면은 자바스크립트로 그려지기 때문에 페이지를 그대로 저장하면 아무 데이터도
나오지 않습니다. 이 앱은 대시보드 뒤에 있는 데이터 API를 따라가 원본을 받아옵니다.

- 대상 대시보드: https://experience.arcgis.com/experience/00a0cfe6bcf94fa4a3c36a0b742b2b45
- 다루는 자료: 광구(승인/신청), 광물 분포·잠재력, 지질, 활성단층, 지질재해, 수문 등

---

## 설치와 실행

파이썬 3.10 이상이 필요합니다. 그 외에는 아래 방법이 알아서 처리합니다.

### 가장 쉬운 방법 (권장)

- **Windows** — `run.bat` 을 더블클릭
- **macOS / Linux** — 터미널에서 `./run.sh`

처음 한 번은 가상환경을 만들고 필요한 패키지를 설치하느라 몇 분 걸립니다.
두 번째부터는 바로 뜹니다. 브라우저가 자동으로 열리고, 종료는 창에서 `Ctrl+C`.

### 직접 명령어로 하고 싶다면

⚠️ 아래 명령은 **한 줄에 하나씩** 실행하세요. 여러 줄을 이어 붙이면
`Invalid requirement` 같은 오류가 납니다.

**Windows (PowerShell)**

```powershell
cd mgb_downloader
py -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe -m streamlit run app.py
```

**macOS / Linux**

```bash
cd mgb_downloader
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m streamlit run app.py
```

그다음 브라우저에서 http://localhost:8501 로 접속합니다.

> `python -m streamlit` 형태로 쓰는 이유: 그냥 `streamlit` 이라고 치면
> PATH 설정에 따라 `'streamlit' 용어가 인식되지 않습니다` 오류가 날 수 있습니다.

### 잘 안 될 때

| 증상 | 원인과 해결 |
|---|---|
| `Invalid requirement: '→'` | 명령을 이어 붙여 복사했을 때. 한 줄씩 따로 실행하세요. |
| `'streamlit' 용어가 인식되지 않습니다` | 설치가 안 됐거나 PATH에 없음. `run.bat` 을 쓰거나 위의 `python -m streamlit` 형태로 실행하세요. |
| `app.py: No such file` | 상위 폴더에서 실행한 경우. 먼저 `cd mgb_downloader` 하세요. |
| 이메일을 입력하라고 하며 멈춤 | `.streamlit/config.toml` 이 있으면 안 나옵니다. 이 파일이 지워졌는지 확인하세요. |
| 포트가 이미 쓰인다는 메시지 | 이전에 띄운 앱이 살아 있는 경우. 그 창에서 `Ctrl+C` 로 끄거나 다른 포트를 쓰세요. |

### 사내망에서 SSL 오류가 날 때

회사 네트워크에 SSL 검사 장비가 있으면 파이썬의 인증서 검증이 실패합니다
(`CERTIFICATE_VERIFY_FAILED`). 앱이 이걸 감지하면 **자동으로 `curl`로 전환**하므로
보통은 아무것도 안 해도 됩니다. 다만 그런 환경에서는 `curl`이 설치되어 있어야 합니다
(Windows 10 이상 · macOS에는 기본 포함).

## 사용법

1. **레이어 선택** — 두 개의 탭이 있습니다.
   - `대시보드 레이어`: 대시보드가 실제로 쓰는 레이어. 앱을 열면 자동으로 찾습니다.
   - `저장소 전체`: 대시보드에 걸리지 않은 것까지 포함한 전체 서비스 목록.
     버튼을 눌러야 탐색합니다(시간이 좀 걸립니다).

   `전체 선택` 체크박스로 한 번에 고를 수 있습니다.

2. **세부 항목으로 나눠 받기** (해당하는 레이어만)
   대시보드는 광물 분포 같은 레이어를 *하나의 데이터*에 색만 다르게 칠해서
   `Zeolite`, `Tuff`, `Talc` … 처럼 여러 개인 것처럼 보여줍니다.
   기본은 레이어 전체를 한 파일로 받고, 필요하면 여기서 광종을 골라 나눠 받습니다.

3. **WHERE 조건** — 기본값 `1=1`은 전체입니다.

4. **형식** — CSV / GeoJSON / 둘 다.
   CSV는 속성만, GeoJSON은 도형까지 포함합니다.

5. **수집 시작** → 결과가 1개면 그 파일을, 여러 개면 ZIP으로 받습니다.

### WHERE 조건 예시

| 목적 | 조건 |
|---|---|
| 전체 | `1=1` |
| 특정 지역 | `docRegOfc = 'CAR'` |
| 여러 지역 | `docRegOfc IN ('I', 'II', 'III')` |
| 면적 조건 | `totalAreaHas > 1000` |
| 광구 유형 | `tenementType = 'MPSA'` |
| 이름 일부로 찾기 | `tenementName LIKE '%Mining%'` |
| 값이 비어있지 않은 것 | `docProvName IS NOT NULL` |
| 조합 | `tenementType = 'MPSA' AND totalAreaHas > 500` |

- 문자열은 **작은따옴표**로 감쌉니다. 큰따옴표는 안 됩니다.
- 필드 이름은 레이어마다 다릅니다. 잘 모르겠으면 먼저 `1=1`로 조금 받아 열 이름을 확인하세요.
- 조건이 틀리면 0건이 나오거나 오류가 납니다. 0건이면 앱이 경고로 알려줍니다.

## 안전 한도

서버에 부담을 주지 않고, 실수로 대용량을 끌어오는 것을 막기 위한 장치입니다.

| 항목 | 값 |
|---|---|
| 레이어당 최대 | 50,000건 |
| 실행당 최대 | 100,000건 |
| 요청 간격 | 기본 0.3초 (사이드바에서 조절) |
| 재시도 | 429·5xx일 때 최대 4회, 간격을 2배씩 늘려가며 |
| 리다이렉트 | 따라가지 않음 |
| 허용 호스트 | `www.arcgis.com`, `services7.arcgis.com`, `controlmap.mgb.gov.ph` 만 |

상한에 걸리면 받은 만큼만 저장하고 경고를 띄웁니다. 더 필요하면 WHERE로 범위를
나눠서 여러 번 받으세요 (예: 지역별로).

레이어 하나가 실패해도 나머지는 계속 진행하고, 마지막에 실패 목록과 사유를 보여줍니다.

## 결과 해석 시 주의

### 1. 광구번호는 유일하지 않습니다
하나의 광구가 여러 필지로 나뉘어 **여러 행**으로 들어옵니다.
승인 광구 621행 = 실제 광구 457개, 신청 광구 181행 = 실제 129개.
광구 수를 셀 때는 광구번호(`docTenementNum`)로 중복을 제거하세요.

### 2. 면적 필드는 서비스마다 의미가 다릅니다
- `totalAreaHas` — 광구 **전체** 면적
- `AreaHasParcel` — **필지 하나**의 면적

둘을 같은 열에 놓고 합계를 내면 값이 틀어집니다.

### 3. 이름이 비슷한 서비스가 신·구 두 계열입니다
`저장소 전체` 탭에는 대시보드가 쓰지 않는 구버전이 함께 보입니다.

| 서비스 | 건수 | 최종수정 | 지역범위 |
|---|---|---|---|
| `Approved_Tenements` (신 승인) | 621 | 2026-07 | 전국 16개 |
| `Mining_Tenement_Approved` (구 승인) | 431 | 2023-11 | — |
| `Application_Mining_Tenement` (신 신청) | 181 | 2026-07 | **4개 지역뿐** |
| `Tenement_Application` (구 신청) | 1,077 | 2023-11 | 전국 ~14개 |

**신 신청 서비스는 16개 지역 중 4개만 들어와 있습니다.** 승인(621)보다 신청(181)이
적은 건 실제 현황이 아니라 이관이 덜 끝났기 때문으로 보입니다. 두 신청 서비스는
광구번호가 61개만 겹치므로, 한쪽만 보면 빠지는 자료가 생깁니다.

### 4. 날짜는 원래 숫자입니다
원본은 epoch 밀리초(UTC)입니다. 기본적으로 `YYYY-MM-DD`로 바꿔서 저장하며,
사이드바에서 끄면 원본 숫자가 그대로 나옵니다.

### 5. CSV의 작은따옴표
`=`, `+`, `-`, `@` 로 시작하는 **문자열** 앞에는 작은따옴표(`'`)가 붙습니다.
엑셀에서 그런 값이 수식으로 실행되는 것을 막기 위해서입니다
([CSV 인젝션](https://owasp.org/www-community/attacks/CSV_Injection) 방어).
음수 같은 **숫자는 그대로** 두므로 계산에는 영향이 없습니다.

### 6. 좌표계
GeoJSON은 WGS84(EPSG:4326) 경위도로 나옵니다. QGIS·구글어스에서 바로 열립니다.

### 7. 타일 지도 서비스는 받을 수 없습니다
`controlmap.mgb.gov.ph`의 홍수·산사태 취약성 레이어는 지도 **그림**만 제공하고
개별 데이터를 주지 않습니다. 목록에 조회 불가로 표시됩니다.

## 출처와 이용

MGB가 공개한 자료를 공개된 방식(ArcGIS REST API)으로 받습니다. 로그인이 필요한
자료나 비공개 자료는 다루지 않습니다. 자료를 외부에 쓸 때는 출처(MGB)를 밝히고,
공식 수치가 필요한 경우 MGB에 직접 확인하세요. 이 앱이 받아온 값은 수집 시점의
스냅샷이며, 원본이 갱신되면 달라질 수 있습니다.
